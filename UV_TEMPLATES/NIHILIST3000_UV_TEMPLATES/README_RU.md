# UV-шаблоны «ТВАРЬ ЖРЁТ ТВАРЬ»

В папке лежат два комплекта.

## Рекомендуемые клише для рисования

- `body_artwork_template` — лицевая плоскость корпуса конверта.
- `valve_artwork_template` — клапан конверта.
- `paper_artwork_template` — лист песни; одно клише используется для всех четырёх листов.

Эти файлы имеют реальные пропорции деталей, прозрачный фон и чистый внешний контур. Рисуй текстуры по ним. При подключении готовых файлов UV модели будет нормализована под эти клише без изменения геометрии и анимации.

## Исходная UV-сетка модели

- `body_uv` — корпус конверта.
- `valve_uv` — клапан конверта.
- `paper_uv` — лист песни; один шаблон используется для всех четырёх листов.

Это точная техническая развёртка из текущего `envelope.glb`. Она сохранена для проверки, но рисовать по ней не рекомендуется: исходная модель имеет сильно раздробленные UV боковых поверхностей.

## Форматы

- SVG можно масштабировать без потери качества.
- PNG имеет прозрачный фон; большая сторона каждого рекомендованного клише равна 4096 пикселям.

Помести шаблон верхним слоем над текстурой. Чёрно-белая двойная линия остаётся видимой на светлом и тёмном фоне. Перед экспортом финальной текстуры отключи слой с UV-сеткой.
